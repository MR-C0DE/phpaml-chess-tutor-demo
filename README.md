# Tutor Chess — PHPAML demo

Tutor Chess is a bilingual chess mentor built as a complete AML View demonstration. It combines a reactive PHP interface, a local Stockfish engine, DeepSeek explanations, and persistent lesson history in MongoDB.

The application is intentionally public so developers can inspect a real PHPAML project beyond a starter template.

## What this demo covers

- declarative pages and components with AML View;
- client-side navigation, themes, state, and interactions;
- legal chess moves and strong local analysis with Stockfish 18;
- educational explanations generated by DeepSeek;
- user accounts and saved lessons with PHPAML Data and MongoDB;
- English and French interfaces;
- responsive board and accessible controls;
- production configuration for Render.

## Requirements

- AML CLI 1.7.0-beta.13 or newer;
- a MongoDB database;
- a DeepSeek API key.

AML provides the private PHP and Composer runtimes used by the project.

## Run locally

```bash
git clone https://github.com/MR-C0DE/phpaml-chess-tutor-demo.git
cd phpaml-chess-tutor-demo
cp .env.example .env
aml install
aml serve
```

`aml serve` selects port `8910`, then increments it when the port is already occupied.

Configure these private values in `.env`:

```dotenv
APP_KEY=replace-with-a-long-random-value
MONGODB_URI=mongodb+srv://user:password@example.mongodb.net/
MONGODB_DATABASE=tutorchess
DEEPSEEK_API_KEY=replace-with-your-key
DEEPSEEK_MODEL=deepseek-chat
```

Never commit `.env`. The repository only contains `.env.example` with empty placeholders.

## Test and build

```bash
aml doctor --offline
aml test
aml build
```

The production archive is generated in `output/`. This directory is intentionally excluded from Git because releases and deployments must rebuild it from reviewed source code.

## Project map

```text
public/                         Web entry point and directly served files
src/controllers/               Authentication, game, and tutor endpoints
src/models/                    PHPAML Data entities
src/services/                  DeepSeek and chess lesson services
src/views/pages/               Declarative AML View pages
src/views/components/          Shared interface components
src/views/stylesheets/         Theme and component styles
src/views/assets/              Client scripts, fonts, and Stockfish
tests/                          Application and AML View tests
```

## Architecture and privacy

Stockfish chooses and evaluates moves inside the browser. DeepSeek receives the chess position and educational context required to explain a move; account secrets and MongoDB credentials remain on the server. Saved lessons are associated with the authenticated user.

This is a demonstration application, not a claim of an unbeatable chess system. Stockfish strength depends on browser resources and configured analysis time.
