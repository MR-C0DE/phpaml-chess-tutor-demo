# Code of Conduct

PHPAML contributors, maintainers, and community members are committed to a welcoming, respectful, and harassment-free community.

Be patient and constructive. Discuss ideas and code without attacking people, welcome different experience levels, respect privacy, and obtain consent before sharing private communication.

Harassment, discrimination, threats, sexualized attention, personal attacks, doxxing, publishing private information, and deliberate disruption are not tolerated. This code applies wherever someone represents PHPAML.

Report concerns privately through [SECURITY.md](SECURITY.md). Maintainers may remove content, issue warnings, restrict participation, or ban participants. Conflicts of interest must be disclosed, and retaliation is prohibited.

## Français

La communauté PHPAML s'engage à offrir un environnement accueillant, respectueux et sans harcèlement. Les désaccords portent sur les idées et le code, jamais sur les personnes. Signalez confidentiellement tout problème par le moyen indiqué dans [SECURITY.md](SECURITY.md). Les représailles sont interdites.
