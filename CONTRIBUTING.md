# Contributing

Thank you for helping improve PHPAML. Search existing issues first and keep each proposal focused. Open an issue before a large change; focused fixes, tests, and documentation pull requests are welcome.

Never commit secrets, private URLs, archives, logs, or unredacted environment files. Report vulnerabilities privately through [SECURITY.md](SECURITY.md). Run the documented quality checks and describe the result in the pull request.

English is the primary public language. Keep French content aligned when shared user-facing concepts change.

By contributing, you agree that your contribution is distributed under the [MIT License](LICENSE). Existing copyright and third-party license notices must be preserved.

## Français

Les corrections, tests et améliorations documentaires ciblés sont bienvenus. Ouvrez une issue avant tout changement important, ne publiez aucun secret et exécutez les vérifications documentées.
